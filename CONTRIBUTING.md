# Как помочь

Идеи, ошибки и правки приветствуются.

## Быстрый старт

```bash
git clone https://github.com/auurika/steve-helper.git
cd steve-helper/app
swift test                  # все тесты должны проходить
scripts/build-app.sh        # собрать build/Стив.app
```

Макет в браузере: откройте `mockup/index.html`. Для проверки сна и «жизни в покое» добавьте в адрес `?sleep=10&idle=5`.

## Правила для кода

**Swift** (`app/`)
- Логика без интерфейса живёт в `SteveCore` и покрывается тестами. Если добавляете команду, добавьте фразу в `CommandParserTests`.
- Имена на английском, комментарии и тексты интерфейса на русском.
- Один файл — одна ответственность. Длинные `body` разбивайте на небольшие представления.
- Перед отправкой: `swift build` без предупреждений и `swift test`.

**Макет** (`mockup/`)
- Стили лежат в `styles/`, у каждого файла своя область (окно, боковая панель, чат…). Не добавляйте переопределения в конец чужого файла, правьте нужное правило.
- Скрипты лежат в `scripts/`, каждый модуль подключается к общему объекту `SteveApp` и не лезет в чужие переменные.
- Классы по БЭМ-подобной схеме: `блок`, `блок-часть`, `блок--вариант`, состояния `is-…`.
- Пользовательский текст в HTML вставляйте только через `textContent` или `escapeHtml`.
- Отступы 2 пробела, строки в одинарных кавычках, `const` по умолчанию, `;` в конце.
- Перед отправкой: `for f in mockup/scripts/*.js; do node --check "$f"; done`.

## Коммиты и запросы

Коротко и по делу: что изменено и зачем. Для изменений интерфейса приложите снимок экрана. `Steve --snapshot <папка>` делает его автоматически.
