# Прототип на Python

Первый прототип Стива, с которого всё началось: Whisper распознаёт речь, модель через Ollama отвечает, макос-синтезатор озвучивает. Остался для экспериментов с промптами и манерой общения. Готовое приложение для Mac находится в [`../app`](../app).

```bash
cd prototype
uv sync --python 3.12
uv run steve --text          # писать с клавиатуры
uv run steve                 # говорить голосом
uv run python scripts/check_tools.py   # проверить, что модель вызывает нужные инструменты
```

Нужны Ollama и модель `qwen3:8b` (`ollama pull qwen3:8b`).
