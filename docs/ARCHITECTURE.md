# Устройство Стива

Приложение разделено на две части, чтобы всё, что можно проверить без интерфейса, проверялось тестами.

```
SteveCore  (логика, без интерфейса, 37 тестов)
  CommandParser    фраза -> Command (таймер, событие, заметка, громкость, открыть приложение…)
  Command          перечень понятых команд и слова-триггеры радости
  StyleFilter      манера ответов: заглавная буква, без «!» и точки, без слов-паразитов, цензура
  SpeechText       что нельзя произносить: кавычки, скобки, разметка, эмодзи
  PitchEstimator   тон голоса по записи (автокорреляция) для «своего голоса»
  SteveAnimator    поза Стива в любой момент времени (для всех анимаций)
  SmallTalk        короткие реплики без модели
  Models           Preset, Hotkey, CustomVoice, AppSettings (с безопасной загрузкой старых настроек)

Steve  (приложение)
  AppModel            состояние: диалог, статус, настройки, голос; склеивает всё остальное
  Services/Tools      выполнение команд: «Заметки», «Календарь» (EventKit), громкость, таймер
  Services/Listener   распознавание речи на устройстве (SFSpeechRecognizer + AVAudioEngine)
  Services/Speaker    озвучка (AVSpeechSynthesizer), личные голоса, тон своего голоса
  Services/HotkeyManager  глобальное сочетание (Carbon) и запись нового сочетания
  Character/          Стив: рисование (Canvas) и «жизнь» (моргание, сон, взгляд)
  Views/              окно, боковая панель, диалог, пресеты, настройки, окно из меню-бара
  Theme/Glass         стеклянные поверхности и плашки в стиле Liquid Glass
```

## Путь одной команды

1. Фраза приходит с клавиатуры, из окна меню-бара или с микрофона (`Listener`).
2. `CommandParser.parse` превращает её в `Command`. Команды определяются правилами, поэтому работают мгновенно и без интернета.
3. `Tools.execute` выполняет команду в стандартном приложении и возвращает текст ответа и строку «команды» для показа.
4. `StyleFilter.finalize` приводит ответ к манере Стива, при включённой цензуре убирает мат.
5. `Speaker.speak` озвучивает ответ, предварительно очистив текст через `SpeechText.clean`.
6. Статусы Стива меняются по ходу: «Слушает», «Думает», «Выполняет», «Готов». Пока ответ отправляется, статус остаётся «Выполняет».

Слова вроде «спасибо» и «молодец» определяются отдельно (`JoyWords`): только на них Стив радуется.

## Что решено и почему

- **Распознавание на устройстве.** `requiresOnDeviceRecognition` включается, если язык поддерживает. Так речь не покидает компьютер.
- **Заметки и календарь в стандартных приложениях.** «Заметки» управляются через AppleScript с аргументами через `argv`, чтобы текст пользователя не попадал в код скрипта. Календарь через EventKit.
- **Таймер внутри Стива.** У приложения «Часы» нет программного интерфейса.
- **Закрытие окна не завершает приложение.** Стив остаётся в меню-баре и Dock, как обычная утилита.
- **Без пакета не запускаются микрофон, календарь и уведомления.** Без `Info.plist` macOS аварийно закрывает программу при первом обращении, поэтому в режиме `swift run` эти возможности отключены (`Packaging.isPackaged`).
- **Окна и анимации проверяются без записи экрана.** `Steve --snapshot <папка>` рисует окна в PNG. Так картинки в README делаются автоматически.

## Языковая модель

В готовом приложении свободный разговор пока не включён. Системная модель Apple (Foundation Models) не поддерживает русский язык, поэтому для разговора нужна своя модель внутри пакета. Интерфейс для неё уже есть: протокол `ChatEngine` в `Services/ChatEngine.swift`. Для разработки есть реализация через локальный Ollama:

```bash
STEVE_ENGINE=ollama STEVE_OLLAMA_MODEL=qwen3:8b swift run Steve
```

Этот режим выключен по умолчанию и в сборку для пользователей не входит.

## Проверка анимаций

Сон и «жизнь в покое» можно ускорить переменными окружения:

```bash
STEVE_SLEEP_SECONDS=10 STEVE_IDLE_SECONDS=5 swift run Steve
```

## Макет

Папка `mockup/` содержит кликабельную модель интерфейса в браузере: те же экраны, анимации и поведение окна (перетаскивание, растягивание, кнопки закрыть, свернуть, на весь экран). Она нужна, чтобы обсуждать и править дизайн до реализации. Код макета разбит на модули в `mockup/scripts` и `mockup/styles`.
